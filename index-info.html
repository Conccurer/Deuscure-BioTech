🚀 How to Get Started

  1. Start a local server - Run python -m http.server 8080 from the project folder
  2. Open index.html - Visit http://localhost:8080/index.html
  3. Navigate freely - Use the navigation menu to explore all pages
  4. Test the contact form - Submit the form on the Contact page to verify validation
  5. Browse products - Open product cards and view full information modals
